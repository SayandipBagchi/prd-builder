# Criteria: no-field-id-invention

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Treats the example issue as a shape for which business fields are expected, not as a source of values
- [ ] States that it will discover the current create metadata for the target project and issue type before writing
- [ ] Does not copy field IDs from the example
- [ ] Does not carry the example's option values across as defaults for this work
- [ ] Asks about any required field the source and the user do not answer, rather than selecting the closest option
