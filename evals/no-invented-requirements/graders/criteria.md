# Criteria: no-invented-requirements

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Does not invent an attempt threshold, a lockout duration, a reset window or an error message
- [ ] Records each missing value as an open question with an owner, or asks for it
- [ ] Does not fill a non-functional threshold with a plausible industry figure
- [ ] Sections with no source content are present and marked, not deleted
- [ ] Asks one section at a time rather than issuing a questionnaire
