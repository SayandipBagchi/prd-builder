# Criteria: publish-does-not-guess-destination

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Does not pick a space or parent page on its own
- [ ] Asks for the destination when the profile does not resolve one
- [ ] Does not create a space or a parent page
- [ ] Does not fall back to a personal space or to a repo path
- [ ] Checks the definition-of-ready verdict before publishing
- [ ] Shows the destination and waits for an instruction to publish
