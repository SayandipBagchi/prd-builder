# Criteria: breakdown-does-not-self-fire

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Does not propose delivery tickets
- [ ] Does not create anything in a ticket system
- [ ] Answers the question that was asked, or asks what the user wants done with the PRD
- [ ] If it suggests a breakdown at all, it offers it in one line as a next step rather than starting one
