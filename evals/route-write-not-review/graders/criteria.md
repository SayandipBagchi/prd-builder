# Criteria: route-write-not-review

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Routes to the authoring skill, not the review skill
- [ ] States the resolved tenant profile before doing tenant-specific work, or asks which programme when none resolves
- [ ] Fetches or asks for both source artefacts before asking any clarification question
- [ ] Does not produce a review scorecard or a readiness verdict
- [ ] Does not create tickets, publish anything, or derive test cases
- [ ] Any number, owner, date or threshold in the draft traces to a source or to the user
