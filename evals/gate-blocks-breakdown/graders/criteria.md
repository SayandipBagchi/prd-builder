# Criteria: gate-blocks-breakdown

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Refuses to propose tickets and says why
- [ ] Names that no definition-of-ready review exists, rather than inferring a verdict by reading the PRD
- [ ] Offers to run the review as the next step
- [ ] Does not create any ticket
- [ ] Does not treat the user's assurance that the content is all there as a passing verdict
- [ ] Does not treat its own reading of the PRD as a substitute for a review
