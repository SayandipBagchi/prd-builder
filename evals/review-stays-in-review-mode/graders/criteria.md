# Criteria: review-stays-in-review-mode

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Reviews the PRD
- [ ] Does not rewrite the acceptance criteria
- [ ] Says plainly that the review does not rewrite, and offers the authoring skill for the fix
- [ ] Does not drift into asking clarification questions section by section
- [ ] Describes what each criterion is missing rather than demonstrating a corrected version
