# Criteria: route-review-not-rewrite

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Returns a review, not a rewritten PRD
- [ ] Verdict appears as the first line of the response
- [ ] Verdict is not ready, because success metrics have no baseline and requirements are untestable
- [ ] Scores checks individually rather than giving prose impressions only
- [ ] Cites PRD sections by name for each finding
- [ ] Does not supply a baseline figure, owner or date that the PRD lacks
- [ ] Uses only the buckets Definition-of-Ready Gaps, Needs Clarification and Optional Tightening
- [ ] Uses no code-review severity words such as blocker, critical, major, minor, nit or P0
